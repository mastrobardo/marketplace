# Memory ids are global, and the filename is the id

**Fact.** `MEM-YYYY-MM-DD-NN` is unique across all of `memory/`, not per directory. The repo-wide
and slice sequences were once numbered independently and collided twice on 2026-09-09.

**Why.** `superseded-by MEM-…` and every citation in a run record resolve by id alone, so two
records answering to one id make **both** unresolvable. Naming each file for its id means the two
can never drift.

**Apply.** Check `memory/LONG_TERM.md` before claiming an id. If you must renumber, grep the repo
for the id first — the one already cited in a run record is the one that keeps its number.
