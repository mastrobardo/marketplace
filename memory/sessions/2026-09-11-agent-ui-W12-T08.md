## The two findings worth remembering

**`ratingAvg` cannot be a sortable field.** It is `Decimal?`, and `pagination.ts` throws on a null
sort value because keyset paging over a nullable column loses exactly the null rows. Unrated
providers are the new ones. The spec had it as sortable until it was checked; `Q4` records the fix
(`COALESCE` projection) for whoever wants "best rated" next.

**`import.meta.env.DEV` does not keep a dynamic import out of a production bundle.** Rollup builds
the graph edge before the `false` branch is minified. Measured: 511 KB of MSW plus the seeded
catalogue in `dist/assets/browser-*.js`, *referenced by the entry chunk*. Fixed with a `stripMocks()`
resolve plugin in `vite.config.ts`. This is a general trap, not an MSW one — it applies to any
dev-only dynamic import in this repo.
