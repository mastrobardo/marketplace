## Log
- 15:15 Ordering decision, taken in the T01 handoff and honoured here: stories are written as CSF3
  and exercised through `composeStories` in jsdom. The backlog puts the stories in T02 and Storybook
  in T03, which would otherwise mean writing ~40 stories with nothing to run them against. This way
  T03 is a runner change and none of them is rewritten.
- 15:20 Four things React Aria does that I had assumed wrong, each found by a failing test:
  1. `aria-invalid` never reaches a `Select` trigger — it is a button, and RAC links the error by
     `aria-describedby` instead. Criterion rewritten, dead prop deleted.
  2. RAC closes a combobox menu whose collection is empty, so `renderEmptyState` is unreachable
     without `allowsEmptyCollection` — which kills both of the states the control exists for.
  3. RAC filters an *uncontrolled* collection only. A controlled `items` list is the caller's to
     filter, so typing `zzzz` left every option visible. `useFilter` with `sensitivity: 'base'`.
  4. RAC wraps `renderEmptyState` in a `role="option"` container, so "nothing to choose" is about
     selectable options (the ones with `data-key`), not about the role count.
- 15:30 The build inlined React Aria: 339 KB for one `Button`. Externalised → 8.81 KB. ADR-011's
  ≤170 KB initial-route budget would have failed one task later, on `W12-T09`, and it would have
  looked like the pages' fault.
- 15:35 Finding for `W12-T09`, not fixable here: RAC's built-in strings are **English** by default
  (*"Select an item"*, *"Suggestions"*). The app needs `<I18nProvider locale="es-ES">`. Spec §10 Q3.
