## The findings worth remembering

**A gate nobody has watched fail is not a gate.** AC14 asserts the map is its own chunk. Flattening
`lazy(() => import())` to a static import leaves every behavioural test passing and silently moves
the map into the entry. Probed by hand — it failed with the right message, then restored.

**`SearchQuerySchema` decodes the cursor**, so its *output* cannot be serialised back into a URL:
`cursor` is a `CursorPosition` and `sort` an array. The client takes strings. The same property is
what makes a stale cursor detectable, so a shared paged link degrades to page one instead of 500ing.

**A nested `<ul>` inside a row broke two tests and a screen reader the same way.** `getAllByRole('listitem')`
returned rows and badges together. Badges are spans now.

**A React Aria Select's trigger is named "label + current value"**, so an equality assertion written
against a Combobox fails on it.

**`turbo` replayed a cached `web:test` log** with the pre-ticket total. Running each package directly
gave the real numbers. A figure is evidence only if the run that produced it is the run you are
asking about — second occurrence, see [[marketplace-ci-gates-fail-open]].

**An error boundary has no loader data**, so the rail it renders has no categories — deliberately, and
for the same reason the shell degrades: never a bare `await` on a backlog endpoint from an error page.
