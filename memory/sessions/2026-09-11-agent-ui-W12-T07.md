## Decisions taken before any code

- **Scope is T07 alone**, put to the operator and confirmed. The bundling question was real:
  `W12-T08` freezes `SearchQuery` in `packages/contracts` and the pipeline wants a contract before
  an implementation. It does not apply here, because `tests/boundaries.test.ts` AC15 forbids
  `packages/ui` from importing `packages/contracts` at all — so T07 touches no seam and needs no
  freeze. The proposal for T08 goes in the run record instead.
- **`name: string`, not a union of our four field names** — ADR-011 §3's own third consequence
  ("a second vertical is a different schema") makes a compiled-in union wrong for this layer.
- **`options: Option[]` on every field** rather than the ADR's `Urgency[]`/`JobMode[]`, for the same
  boundary reason. Same `{ id, label }` the `Select` and `Combobox` already take.
- **One component with a `rendering` prop**, not three components — drift is the failure the task
  exists to prevent. Spec §10 Q2 carries the argument and the point at which to split.
- `geolocate` deferred to `W12-T09`: a permission prompt is not a pure renderer's business.

## Running notes

- Primitives take every string as a prop (`W12-T02`); the pattern does the same — submit label,
  expand label, error messages all arrive from the caller.
- New component tokens land in `src/styles/components.css`. `token-graph.ts` classifies anything
  that is not `--mp-palette-*` or a semantic name as a component token, so `--mp-search-*` needs no
  change to the gate.
- `boundaries.test.ts` AC16 only looked at `./primitives/…` exports. Widening it to any exported
  module whose filename is capitalised is AC12 of this spec.
