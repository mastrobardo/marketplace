## The findings worth remembering

**A boundary belongs at the level that actually failed.** A 404 handled at the root costs the visitor
the header, the search box and the footer for a typo. The legal route got its own `ErrorBoundary`;
the root one is now only for "the shell itself broke".

**A thrown `Response` only becomes a 404 from a loader.** Thrown during render it is a React error
that unmounts the tree. Route-param validation goes in the loader.

**`/:lang` matches anything**, so an unknown language rendered the Spanish home page at someone
else's URL, returning 200. The loader throws 404 now. And do not add a sibling `path: '*'` — it is
unreachable under `/:lang`, and an unreachable route reads as handled.

**The SPA answers 200 for every path**, measured with curl — the 404 is a rendering, not a status.
Escalated as Q2, parked on `W12-T14`.
